বাজার দর — Project Description
Technologies Used: Next.js, React, Tailwind CSS, REST API
Description: A responsive web application that displays daily market prices of essential products in Bangladesh, including price increases, decreases, and current prices.
Key Features
1. Daily Price Updates – View current prices of essential market products.
2. Price Change Tracking – Identify products whose prices have increased or decreased.
3. Product Details – View detailed information and pricing for individual products.
4. Category Navigation – Browse products by category.
5. Responsive Design – Smooth browsing experience on desktop, tablet, and mobile devices.
